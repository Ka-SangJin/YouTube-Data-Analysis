# YouTube Trending Video Analysis
### 유튜브 인기 동영상 데이터 분석 및 성공 요인 도출

## 1. 프로젝트 개요

한국 유튜브 인기 동영상 데이터를 분석하여 조회수와 좋아요에 영향을 미치는 요인을 파악하고, 머신러닝을 활용해 효과적인 영상 업로드 전략을 도출한 프로젝트입니다.

## 2. 개발 환경 및 기술

- **Language:** Python
- **Environment:** Google Colab, Jupyter Notebook
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn (Random Forest)

## 3. 프로젝트 진행 과정

**① 데이터 수집 및 전처리**
- Kaggle의 한국 유튜브 인기 동영상 데이터 활용
- 결측치 및 이상치 제거
- 업로드 시간, 요일, 태그 개수, 제목 길이 등 파생변수 생성
- 최종 33,875건의 데이터 분석

**② 탐색적 데이터 분석(EDA)**
- 조회수, 좋아요, 댓글 수 간 상관관계 분석
- 카테고리별 평균 조회수 비교
- 업로드 요일 및 시간대별 조회수 분석
- 태그 개수와 조회수의 관계 분석

**③ 머신러닝 모델 학습**
- Random Forest 회귀 모델 활용
- 조회수 및 좋아요 예측
- Feature Importance를 통한 주요 영향 변수 분석

**④ 결과 분석 및 전략 도출**
- 조회수와 좋아요에 영향을 미치는 주요 변수 확인
- 데이터 분석 결과를 기반으로 영상 업로드 전략 제안

## 4. 주요 결과

| 평가 항목 | 결과 |
|---|---|
| 조회수 예측 R² | 0.61 |
| 좋아요 예측 R² | 0.63 |
| 조회수 주요 변수 | 제목 길이 |
| 좋아요 주요 변수 | 태그 개수 |
